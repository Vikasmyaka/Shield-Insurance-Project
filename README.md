# 🛡️ Shield Insurance Analytics Dashboard

## 📊 Project Overview

An interactive Power BI dashboard developed to analyze insurance business performance, customer trends, revenue growth, sales channels, and demographic insights.

## 🚀 Key Features

✅ General Business Analysis
✅ City-wise Revenue Insights
✅ Sales Channel Performance
✅ Age Group Segmentation
✅ Monthly Trend & Seasonality Analysis
✅ Interactive KPI Cards & Visualizations
